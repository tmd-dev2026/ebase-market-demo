# eBaseマーケット(デモ)

AI出品の体験用に、仕入れ先の商品ページを再現した日本語の静的サイトです。6 商品・24 枚のオリジナル SVG イラストを収録しています。商品、出品者、価格はすべて架空の例です。購入・取引・決済・ログイン機能はありません。

一覧で商品を選び、商品ページの「このページの URL をコピー」を押して、別サイトの体験版の「AI出品」に貼り付けます。体験版の行き先は `assets/js/config.js` の `MarketConfig.appUrl` で指定します。このリンクは新しいタブで開きます。

## ローカル確認

依存パッケージのインストールは不要です。リポジトリ直下で実行します。

```sh
node scripts/build.js
node tests/market.test.js
python3 -m http.server 8000
```

ブラウザで localhost のポート 8000 を開きます。または `index.html` を直接開いて `file://` でも確認できます。カテゴリ絞り込み、画像切替、テーマ切替はローカルでも動きます。商品カードと説明文は生成 HTML に含まれるため、JavaScript が無効でも読めます。

クリップボードが利用できない・拒否される場合は、常時表示される読み取り専用の URL 欄にフォーカスして全選択し、長押しでのコピーを案内します。パソコンでは Ctrl+C / ⌘C も使えます。コピーする値は現在の URL からクエリとハッシュを除いたものです。ローカルファイルの URL は別の環境から参照できないため、参加者に配布するときは公開先の URL を使ってください。

## 配置（ホスティング側のビルドなし）

生成済みの `index.html`、`items/`、`assets/`、`_headers`、`robots.txt` を同じ階層構造で配置します。JavaScript や CSS のバンドル、環境変数、サーバー処理は不要です。

- GitHub Pages: 生成済みファイルを含むブランチのルートを Pages の公開元に指定します。プロジェクトのサブパス `/ebase-market-demo/` にそのまま配置できます。
- Cloudflare Pages: 同じファイル一式を直接アップロードするか、Git 連携でフレームワークなし・ビルドコマンドなし・出力先をリポジトリルートにします。`_headers` はこのホストでレスポンスヘッダーとして利用されます。

サイト内リンク、画像、CSS、スクリプトはすべて相対パスです。体験版リンクだけが設定済みの外部遷移先です。全 HTML の robots メタタグ、`robots.txt`、`_headers` で検索エンジンへの非掲載を指定しています。ホスティング環境によって `_headers` の対応は異なります。これらはアクセス制限の機能ではありません。

## データ・URL・再生成

商品データの単一の情報源は `assets/js/products-data.js` です。この実装では提供データを変更していません。`scripts/build.js` が商品一覧と 6 商品ページを生成します。

商品 URL の規則は `items/<slug>.html` です。例: `items/film-camera.html`。表示順と前後のリンクはデータの順序に従います。HTML の生成は次のコマンドで行います。

```sh
node scripts/build.js
```

商品ページの生成 HTML を直接編集せず、表示構造の変更は `scripts/build.js` に加えて再生成してください。生成結果もリポジトリで管理する想定です。カテゴリの日本語表示は生成スクリプト内で定義しています。

## イラストと写真の差し替え

`assets/img/<slug>-<n>.svg`（各商品 1〜4）を同名ファイルで置き換えると、リンクを変更せずに差し替えられます。800×800、同じ viewBox、タイトルと画像の意味、各商品の `images[].caption` に対応する構図を維持してください。各 SVG は外部参照なし・200KB 以下です。画像内にはブランドのロゴ、読める文字、実在キャラクターを含めていません。日付・曜日の窓も文字なしです。

実写真を同名 SVG で置く場合は、写真データを SVG 内に埋め込む必要があります。拡張子だけを変えた写真は使えません。現在の画像テストは外部依存のないベクターイラストを対象としているため、写真を採用する際はサイズと埋め込み方式に合わせて画像テストも見直してください。

24 枚のイラストは `scripts/illustrations.js` で再現できます。

```sh
node scripts/illustrations.js
```

このコマンドは同名の全イラストを上書きします。写真への差し替え後は実行しないでください。通常のページビルドでは画像を変更しません。

## テストと実装上の判断

`node tests/market.test.js` は Node の標準機能と `assert` のみを利用します。データ件数、SVG 構造、容量、ローカル参照、生成結果の一致と再生成の安定性、禁止表現、配色の文字コントラスト、商品情報と警告の出し分けを検査します。DOM の代用オブジェクトでカテゴリ、ギャラリーのキー操作、コピー成功と失敗、保存領域が使えない場合のテーマ切替を検証します。実ブラウザのレイアウトや OS のクリップボードそのものを検証するテストではありません。

全 JavaScript の構文検査は次でも実行できます（禁止されたディレクトリを探索しません）。

```sh
node --check assets/js/products-data.js
node --check assets/js/config.js
node --check assets/js/market.js
node --check scripts/build.js
node --check scripts/illustrations.js
node --check tests/market.test.js
```

静的検査の対象は配布ファイル・実装・テスト・この README です。禁止例自体を引用している `BRIEF.md` と、リポジトリ・ツールの管理ディレクトリは対象外です。SVG の標準 XML 名前空間宣言は識別子であり通信を行わないため、外部 URL 検査で例外にしています。外部遷移先の定義は `config.js` のみ許可します。

「購入する」は無効状態に見えるボタンと `aria-disabled` で表し、実際の取引を行わずクリックや Enter / Space でデモの案内だけを出します。画像は標準ボタンで Tab / Enter / Space、加えて矢印 / Home / End キーでも操作できます。保証書のないバッグだけに赤い真贋の注意文を出します。

テーマはシステム設定に従い、ボタンを押すと選択を保存します。保存が使えなくても現在のページでは切り替わります。ライト・ダークの文字色と背景色はテストで 4.5:1 以上を確認します。

実ブラウザでの見た目はこの作業環境では未確認です。公開前に 360px 幅、ダークモード、キーボード、支援技術、実機でのコピー操作、各ホストのサブパスでの遷移を確認してください。
